# TournamentLab – AI Learning Log

## 1. Purpose of AI Assistance

AI was used as a learning and debugging assistant throughout the development of TournamentLab.

The goal was not simply to generate working code, but to understand the concepts, implementation decisions, and reasoning behind the application.

## 2. Areas Where AI Assisted

AI assistance was used for:

- Breaking the project requirements into manageable development stages.
- Understanding Python functions, loops, dictionaries, lists, and sets.
- Understanding nested loops for round-robin fixture generation.
- Implementing input validation and exception handling.
- Understanding how to calculate league standings.
- Working with JSON file storage and data validation.
- Writing and understanding automated tests with `unittest`.
- Debugging errors and improving edge-case handling.
- Structuring the application into independent modules.

## 3. Learning Approach

Development followed an incremental approach:

1. Understand the requirement before implementation.
2. Break complex problems into smaller tasks.
3. Attempt to reason through the solution.
4. Use AI explanations when a concept or error was unclear.
5. Implement the solution and test its behaviour.
6. Review the result and understand why it works.

AI-generated suggestions were reviewed and tested rather than accepted blindly.

## 4. Key Concepts Practised

The project provided practical experience with:

- Modular Python programming.
- Functions and separation of responsibilities.
- Lists, dictionaries, sets, and nested loops.
- Input validation and exception handling.
- Sorting with custom keys.
- JSON serialization and deserialization.
- File handling.
- Unit testing and test-driven verification.
- Data integrity and application design.

## 5. Testing and Verification

The project was verified using Python's built-in `unittest` framework.

At the time of this log, **26 automated tests passed**.

Testing covered team registration, fixture generation, invalid scores, duplicate results, standings calculations, and tournament data persistence.

## 6. Reflection

Working on TournamentLab helped strengthen my understanding of how individual Python concepts come together to build a complete application.

I learned the importance of separating responsibilities, validating data, writing tests, and thinking about edge cases before they become problems.

The experience also reinforced the importance of understanding AI-assisted code, reviewing implementation decisions, and being able to explain the solutions independently.

## 7. Conclusion

AI supported the development process, but learning, implementation, testing, and reviewing the project remained central to the experience.

TournamentLab represents a practical step in my growth as a Python developer.
